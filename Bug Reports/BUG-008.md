# BUG-008: App freezes and a partial record is saved when the internet is lost while saving a vaccination record

| Field | Details |
|---|---|
| **Bug ID** | BUG-008 |
| **Module** | Vaccination |
| **Related test case** | TC-40 |
| **Severity** | High |
| **Priority** | Medium |
| **Status** | Open |
| **Reproducible** | Always |
| **Environment** | Google Chrome, desktop, https://farm-fusion-manage.vercel.app |
| **Reported by** | Muhammad Ali Khan |
| **Date reported** | November 2026 |

## Steps to reproduce
1. Log in with a valid account.
2. Open Vaccination and start adding a record with valid details.
3. Turn off the internet.
4. Click Save.

## Test data
Valid record details, no internet

## Expected result
A clear error message should be shown, no wrong or partial record should be saved, and the app should not freeze.

## Actual result
No error message is shown, a wrong or partial record is saved, and the app freezes.
