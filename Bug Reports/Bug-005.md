## Steps to reproduce
1. Log in with a valid account.
2. Open Breeding.
3. Select an existing breeding record.
4. Change the breeding date.
5. Click Save.

## Test data
Existing record, new breeding date

## Expected result
The changes should be saved and the expected birth date should be updated to match the new breeding date.

## Actual result
The changes are not saved and the expected birth date is not updated.
