# BUG-006: Duplicate animal type can be added in Settings without any message

| Field | Details |
|---|---|
| **Bug ID** | BUG-006 |
| **Module** | Settings |
| **Related test case** | TC-34 |
| **Severity** | Low |
| **Priority** | Medium |
| **Status** | Open |
| **Reproducible** | Always |
| **Environment** | Google Chrome, desktop, https://farm-fusion-manage.vercel.app |
| **Reported by** | Muhammad Ali Khan |
| **Date reported** | November 2026 |

## Steps to reproduce
1. Log in with a valid account.
2. Open Settings.
3. Add an animal type that already exists (Cow).
4. Click Save.

## Test data
Cow added twice

## Expected result
The duplicate should be rejected with a message, or handled as designed.

## Actual result
The duplicate is not rejected, no message is shown, and it is not handled as designed.
