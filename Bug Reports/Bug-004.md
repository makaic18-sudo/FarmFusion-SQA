# BUG-004: Vaccination record accepts an invalid date (31/02/2026)

| Field | Details |
|---|---|
| **Bug ID** | BUG-004 |
| **Module** | Vaccination |
| **Related test case** | TC-23 |
| **Severity** | Medium |
| **Priority** | Medium |
| **Status** | Open |

| **Environment** | Google Chrome, desktop, https://farm-fusion-manage.vercel.app |
| **Reported by** | Muhammad Ali Khan |
| **Date reported** | November 2026 |

## Steps to reproduce
1. Log in with a valid account.
2. Open Vaccination.
3. Choose the add option.
4. Enter an impossible date (31/02/2026).
5. Fill in the other fields and click Save.

## Test data
Date: 31/02/2026

## Expected result
The invalid date should be rejected with a validation message.

## Actual result
The invalid date is not rejected and no validation message is shown.
