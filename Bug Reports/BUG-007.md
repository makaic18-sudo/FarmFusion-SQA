# BUG-007: Farm name in Settings is not limited and a very long text with special characters is accepted

| Field | Details |
|---|---|
| **Bug ID** | BUG-007 |
| **Module** | Settings |
| **Related test case** | TC-35 |
| **Severity** | Medium |
| **Priority** | Low |
| **Status** | Open |
| **Reproducible** | Always |
| **Environment** | Google Chrome, desktop, https://farm-fusion-manage.vercel.app |
| **Reported by** | Muhammad Ali Khan |
| **Date reported** | November 2026 |

## Steps to reproduce
1. Log in with a valid account.
2. Open Settings.
3. Enter a very long farm name (200+ characters) with special characters.
4. Click Save.

## Test data
200+ characters and @#$%^&

## Expected result
The input should be limited or saved safely, with no crash or broken layout.

## Actual result
The input is not limited and is not saved safely.
